What this is not

A support classifier with a measured error rate, not an authority. It reads the host name only: it cannot resolve shorteners like bit.ly, cannot see page content, and will miss phishing hosted on compromised legitimate domains — 321 hosts in the evaluation data are exactly that case. At its 1 % false-positive operating point it catches roughly — of phishing, so it misses the rest. Do not treat a “legitimate” verdict as safety.

Trained on PhiUSIIL (UCI id 967) after removing two measured label leaks; evaluated against PhishTank hosts submitted after the training data was collected. Phishing maps to MITRE ATT&CK T1566 / T1566.002. Source and full report on GitHub.
